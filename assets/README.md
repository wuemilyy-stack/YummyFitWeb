# assets/

Drop your hero background video here:

- `hero.mp4` — full-width background loop for SECTION 1 (Hero), ideally 5–7 seconds,
  H.264/MP4, 1920×1080 or larger, muted audio, seamless loop, under ~8 MB.

If the file is missing, the hero automatically falls back to its animated
gradient background — the page always looks complete.
